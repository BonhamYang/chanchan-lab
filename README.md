# 铲铲实验室 (Chanchan Lab)

在现有项目上开发的金铲铲国服阵容与装备统计助手，支持自然之力及画之灵的数据结构。

网站：https://chanchan-lab.onrender.com

## 已实现

阵容统计排序与赛季/版本/模式/段位筛选、三件套查询、CSV 名次计数聚合、浏览器本地导入、图鉴与阵容编辑器、授权快照更新校验及只读 HTTP 服务。

**已支持浏览器按需从腾讯官网读取双赛季图鉴与单棋子组合统计**，仅存本机，服务器不镜像游戏资料。自然之力单棋子三件套已实测可用；画之灵统计、全服阵容榜和严格分模式比较尚未完成。未知样本量和统计版本明确标注，不凭空生成。

## 运行与验证

```sh
python server.py
python -m unittest discover -v
python -m unittest discover -s tests -v
node test_import_stats.js
node --check catalog.js
node --check item-analyzer.js
node --check import-stats.js
```

默认端口 8765，Render 使用环境变量 PORT。

## 数据接入

查看 DATA_SOURCES.md、DATA_PIPELINE.md、STATIC_CATALOG_IMPORT.md 和 CSV_IMPORT_GUIDE.md。

公开统计只能接入独立核实且允许存储与展示的金铲铲国服数据。TFT 国际服及历史返场前版本不能替代目标数据。不要提交密钥、个人信息或未经许可的数据。

## 我的实战数据

`/match-journal.html` 支持结算页手动记录 → 对局 ID 去重 → 本地备份与合并 → 自动生成个人阵容和三件套统计。记录仅留在浏览器，不读取账号。只支持八名个人排名；双人四队名次不混算。新增测试：`node test_match_data.js`。

这条路线能积累真实个人样本，不能替代全服榜单。官方合作线索和可发送申请见 DATA_PARTNERSHIP_REQUEST.md。

## 官网直读试接入

进入 `/catalog.html` → 选择赛季 → 点击「从官网读取本赛季资料」。资料直接从腾讯官网加载并保存在本机，支持棋子、装备、羁绊查询与阵容羁绊档位。

在已读取的棋子卡片点击「查官方三件套」，可按需读取该棋子的官方组合统计并跳转分析器。只展示完整三件套；未知样本量、统计补丁、分段名称和玩法范围明确标注。当前验证到自然之力的一名棋子有近期组合数据，画之灵样本未返回有效统计。尚不支持严格的分模式对比或完整全服阵容榜。

官方直读与服务器授权快照是两条独立链路，本站不在服务器镜像直读资料。新增校验：`node test_official_data.js`。

### 官网阵容变体（本机直读）

打开 `/official-lineups.html` 并点击「从官网读取 / 更新阵容」，可查询经过所选赛季（自然之力或画之灵返场）棋子与羁绊双重映射的官方阵容变体。支持前四率、登顶率、平均排名、来源使用次数排序和筛选，包含核心棋子与装备组。统计补丁、玩法和分段名称缺失会明确标注，不提供未经核实的跨模式比较。此功能不写入公共快照，不执行全量后台采集。

### 使用流程更新

首页 `/` 直接提供真实阵容榜；原公共/本地快照导入页保留在 `/index.html`。阵容卡片可展开查看棋子费用、羁绊计数及档位、核心棋子与来源装备组；点击载入编辑器保存完整阵容，并将原阵容备份供恢复。编辑器最多12位，实际人口与特殊机制以游戏内为准。

从详情点击棋子可单次查询三件套并保留赛季、分段与返回路径。目前支持大师以上和全部段位；阵容接口的分段1为钻石以上，三件套接口的分段1为铂金至钻石，因口径不同禁用直接跳转。三件套的玩法仍未细分，不与阵容玩法做等同解释。
