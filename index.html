导入合法获取的统计数据

导入 JSON 文件，包含 comps、items 数组。每条记录需有 season（nature/ink）、name、patch、sample_count、top4_count、win_count、rank_sum。items 另需 unit 和 items（三件装备数组）。百分比由样本计数计算，不接受仅填胜率的记录。

查看 JSON 示例（所有数值为格式示意，非真实胜率）
